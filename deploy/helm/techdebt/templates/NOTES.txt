1. Check resources:
   kubectl get all -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }}

2. Access the UI:
{{- if eq .Values.frontend.service.type "NodePort" }}
   NodePort: http://<NODE_IP>:{{ .Values.frontend.service.nodePort }}

   Then open: http://localhost:{{ .Values.frontend.service.port }}
{{- end }}

3. Backend API:
{{- if eq .Values.backend.service.type "NodePort" }}
   http://<NODE_IP>:{{ .Values.backend.service.nodePort }}/health
{{- else }}
   kubectl port-forward svc/{{ include "techdebt.backendServiceName" . }} -n {{ .Release.Namespace }} {{ .Values.backend.service.port }}:{{ .Values.backend.service.port }}
{{- end }}

4. Portal login:
   Open the UI and sign in with AWS Access Key ID and Secret Access Key (read-only credentials recommended).
